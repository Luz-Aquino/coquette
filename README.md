# Coquette NFM

Tienda online de ropa femenina: **https://coquette.novafamilymarket.com**

- `index.html`, `app.js`, `styles.css`: la tienda.
- `admin.html`, `admin.js`, `admin.css`: panel de administración.
- `config.js`: dirección del servidor y del inicio de sesión con Google.
- `servidor/`: copia del código de Google Apps Script (catálogo, pedidos, Mercado Pago y mails).
